# Structured Programming

O.-J. Dahl、E. W. Dijkstra、C. A. R. Hoare 的英文著作（1972）。以下路径均相对于本目录。

## 推荐阅读版本与导航

优先阅读按篇组织的 LaTeX 正文：英文在 `chapters/`；三篇中文阅读版在 `chapter-zh/`，同名文件对应同一篇。两个目录各仅有三个章节文件。按阅读语言选择即可，正文可直接读取并引用行号。

- 英文序言：在 `full/structured-programming.tex` 搜索 `\chapter*{PREFACE}`；中文阅读版仅包含三篇正文及篇末参考文献。
- `chapters/chapter01.tex`：Dijkstra，Notes on Structured Programming，17 节。
- `chapters/chapter02.tex`：Hoare，Notes on Data Structuring，12 节。
- `chapters/chapter03.tex`：Dahl 与 Hoare，Hierarchical Program Structures，7 节。
- 在各篇中搜索 `\section`、`\subsection` 定位小节；插图在 `images/chap1/`、`images/chap2/`、`images/chap3/`，有 PDF 和 SVG 文件。

## 其他格式

`original/original.pdf` 是带 OCR 文本层的原书扫描 PDF（227 页）。整书 `.tex`、编译 PDF 作为同一作品的其他阅读格式处理，无需在阅读推荐正文后重复读取。各 PDF 的页码不能直接互换。
