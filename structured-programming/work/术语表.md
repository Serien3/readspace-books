## 翻译约定

- `chapter-zh/chapter01.tex`、`chapter-zh/chapter02.tex`、`chapter-zh/chapter03.tex` 与 `chapters/` 的同名文件一一对应，按原文 section 顺序逐节翻译，保留 subsection 和 subsubsection 层级。
- 译文应完整保留论证、限定条件、例子和作者语气。按照自然中文重组句子，不作摘要，不增加正文没有的结论。

- 原文中的实质性疑点记录在本目录 README 的校读说明中；不凭推测改写公式或算法。
