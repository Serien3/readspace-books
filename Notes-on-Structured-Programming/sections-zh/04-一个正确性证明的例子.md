# 四、一个正确性证明的例子

考虑以下程序片段，其中整数常量 a、d 满足 `a ≥ 0` 且 `d > 0`。

```text
integer r, dd;
r ≔ a; dd ≔ d;
while dd ≤ r do dd ≔ 2 * dd;
while dd ≠ d do
    begin dd ≔ dd / 2;
        if dd ≤ r do r ≔ r - dd
    end
```

为应用线性搜索定理（参见第三章“数学归纳法”），考虑如下序列：

$$dd_0=d,\qquad dd_i=2dd_{i-1}\quad(i>0).$$

用通常的数学方法可以导出：

$$dd_n=d\times2^n. \tag{1}$$

这些方法也告诉我们：因为 d > 0，对有限的 r，总存在有限的 k，使 ddₖ > r。因此，第一个循环必定终止，终止时 `dd = d × 2ᵏ`。

将递推关系 `ddᵢ = 2 × ddᵢ₋₁` 对前一项求解，得到 `ddᵢ₋₁ = ddᵢ / 2`。线性搜索定理因而告诉我们，第二个循环也会终止。事实上，第二个循环的循环体执行次数与第一个完全相同。

第一个循环终止时，`dd = ddₖ`，因此：

$$0\le r<dd. \tag{2}$$

如第三章“枚举”中所示，第二个循环的循环体保持这一关系不变。循环终止后，根据 `while dd ≠ d do`，可以断定 `dd = d`。结合 (2)，得到：

$$0\le r<d. \tag{3}$$

此外，我们证明，初始化后始终有：

$$dd\equiv0\pmod d. \tag{4}$$

例如，这可由 (1) 导出：`dd` 的可能值为 `d × 2ⁱ`，其中 `0 ≤ i ≤ k`。

下一步，验证在对 `r` 初次赋值后，下式始终成立：

$$a\equiv r\pmod d. \tag{5}$$

1. 初始赋值之后，它成立。
2. 第一个循环的循环体 `dd ≔ 2 * dd` 保持 (5) 不变，因此整个第一个循环保持 (5) 成立。
3. 第二个循环的循环体包含两条语句。第一条 `dd ≔ dd / 2` 保持 (5) 不变；第二条也保持它不变，因为它或者不改变 `r`，或者从 `r` 中减去 `dd` 的当前值，而由 (4)，这一操作仍保持 (5) 成立。因此，整个第二个循环的循环体保持 (5) 不变，整个循环也就保持 (5) 不变。

结合 (3)、(5)，最终值满足：

$$0\le r<d,\qquad a\equiv r\pmod d.$$

即，r 是 a 除以 d 所得的最小非负余数。

## 4.1 说明一：同时求商

下面的程序还会把相应的商赋给 q：

```text
integer r, dd, q;
r ≔ a; dd ≔ d; q ≔ 0;
while dd ≤ r do dd ≔ 2 * dd;
while dd ≠ d do
    begin dd ≔ dd / 2; q ≔ 2 * q;
        if dd ≤ r do begin r ≔ r - dd; q ≔ q + 1 end
    end
```

证明可以通过考察以下关系的不变性完成：

$$a=q\times dd+r.$$

这个例子来自我的同事 N. G. de Bruijn。

## 4.2 说明二：循环不变式定理

在“数学归纳法”小节中，我们证明了线性搜索定理。上述证明又使用了另一个关于循环的定理：若进入循环前某个关系 P 成立，且一次循环体执行不会破坏其真实性，那么循环终止后 P 仍然成立。这个定理显然也只能用数学归纳法证明，但证明很简单，留作读者练习。

这是十分有用的定理，常常使我们无须显式诉诸数学归纳法。还可以把它表述得更精确：对于循环

```text
while B do S
```

须证明 S 具有这样的性质：执行 S 前 `P and B` 为真，蕴含执行后 P 为真。

## 4.3 说明三：一个练习

下面的练习由美国匹兹堡卡内基梅隆大学的 James King 提供，在此致谢。

设 A、B、x、y、z 为整数，且 A > 0、B ≥ 0。证明下列程序执行后，最终有 z = Aᴮ：

```text
x ≔ A; y ≔ B; z ≔ 1;
while y ≠ 0 do
    begin if odd(y) do begin y ≔ y - 1; z ≔ z * x end;
        y ≔ y / 2; x ≔ x * x
    end
```

证明必须表明：尽管有 `y ≔ y / 2`，所有变量仍保持整数值。方法是证明以下关系的不变性：

$$x>0\quad\text{且}\quad y\ge0\quad\text{且}\quad A^B=z\times x^y.$$

> **译注**：所据文本写作 `y > 0`，并将 `x^y` 的指数写为大写 `Y`。这里将条件校订为 `y ≥ 0`，指数统一为变量 y；因为初始允许 B = 0，而循环终止时也恰有 y = 0。严格的正值条件不能作为这里的全程不变式。
