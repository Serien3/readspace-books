# 术语对照

以下为译者补充，便于全书检索与对照。

| 英文 | 本译文采用的中文 | 含义或用法 |
| --- | --- | --- |
| structured programming | 结构化程序设计 | 以可理解、可论证的结构组织程序及计算 |
| program composition | 程序构造 | 包括分解、选择、组合和细化的设计过程 |
| step-wise program composition | 逐步构造程序 | 每一步尽量少作决定，逐步加入细节 |
| refinement | 细化 | 进一步规定动作的算法或数据的表示 |
| computation | 计算／计算过程 | 按上下文指运行中的过程，区别于静态程序文本 |
| net effect | 净效果 | 一项动作整体产生的效果，抽去内部步骤 |
| primitive action / operation | 原子动作／基本操作 | 在当前描述层次不再展开内部细节的动作或操作 |
| enumerative reasoning | 枚举推理 | 对有限步骤和分支逐一分析 |
| mathematical induction | 数学归纳法 | 处理循环与递归的主要推理方式 |
| invariance / invariant | 不变性／不变式 | 在指定动作或循环迭代边界保持成立的性质 |
| sequencing control | 执行顺序控制 | 决定动作执行次序、选择与重复的机制 |
| concatenation / selection / repetition | 顺序连接／选择／重复 | 三类计算分解方式 |
| program family | 程序族 | 完成相同或相似任务的一组相关程序 |
| manageability / adaptability | 可管理性／可适应性 | 掌握、修改程序及适应变化的能力 |
| state space | 状态空间 | 机器或程序的可能状态所构成的空间 |
| instruction repertoire / order code | 指令集 | 当前机器所提供、可调用的指令集合 |
| closed subroutine | 闭式子程序 | 通过调用进入、完成后返回调用处的子程序 |
| procedure activation / incarnation | 过程激活／一次“化身” | 过程的一次动态执行及相应局部环境 |
| re-entrant code | 可重入代码 | 可同时存在多个执行实例的代码 |
| own variable | `own` 变量 | ALGOL 60 中意图跨过程激活保留值的局部变量；正文保留关键字并讨论其局限 |
| scope / life-time / identity | 作用域／生命期／身份 | 变量的可见范围、存在时间以及所指的具体变量 |
| virtual machine | 虚拟机器 | 在当前抽象层次假定可用、由下层模拟的机器 |
| textual index / dynamic index | 文本索引／动态索引 | 分别记录程序文本位置与当前循环迭代序号 |
| pearl / necklace | 珍珠／项链 | 作者对独立细化层与其组合而成程序的比喻 |
| alphabetical order | 字典序 | 按数字符号次序排列，真前缀先于其扩展 |
| backtracking | 回溯 | 不可行时退回先前选择并探索下一候选 |
| partial function | 偏函数 | 仅在所考虑集合的一部分输入上有定义的函数 |
