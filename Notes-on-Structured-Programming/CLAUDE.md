# Notes on Structured Programming

Edsger W. Dijkstra《结构化程序设计札记》（EWD249）。以下路径均相对于本目录。

## 推荐阅读版本与导航

- 优先阅读 `sections/` 中的英文分章 Markdown；中文阅读使用 `sections-zh/` 中的对应分章 Markdown。两者章节编号一致，便于按需对照。
- 英文目录：`sections/00-cover-and-contents.md`；中文目录：`sections-zh/00-封面与目录.md`。先从目录定位章节，再读取对应文件。
- 阅读顺序：目录 → `sections/preface-to-my-reader.md`（中文：`sections-zh/前言-致读者.md`）→ 编号 `01` 至 `14` 的章节。
- 术语对照：`sections/appendix-glossary.md` 或 `sections-zh/附录-术语对照.md`。
- 正文插图位于 `figures/`，分章文件通过相对路径引用。

## 其他版本

`Notes-on-Structured-Programming.md`、`Notes-on-Structured-Programming-zh.md` 和 `Notes-on-Structured-Programming.html` 是同一作品的其他阅读格式。只需阅读推荐的分章 Markdown，无需重复读取其他格式；仅在遇到实质性歧义或怀疑格式、内容转换错误时查阅相关段落。

分章版本包含编辑补充的小节标题、译注和术语表；这些内容不属于作者原文。编排细节见各语言目录文件中的说明。
