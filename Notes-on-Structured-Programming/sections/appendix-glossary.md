# Glossary

The following is an editorial supplement from the translator, provided for reference and comparison throughout the book.

| English | Chinese Used in This Edition | Meaning or Usage |
| --- | --- | --- |
| structured programming | 结构化程序设计 | Organising programs and computations through structures that can be understood and reasoned about |
| program composition | 程序构造 | The design process, including decomposition, selection, composition and refinement |
| step-wise program composition | 逐步构造程序 | Making as few decisions as possible at each step and progressively adding detail |
| refinement | 细化 | Further specifying an action’s algorithm or a datum’s representation |
| computation | 计算／计算过程 | Depending on context, the process during execution, distinguished from static program text |
| net effect | 净效果 | The overall effect of an action, abstracting from its internal steps |
| primitive action / operation | 原子动作／基本操作 | An action or operation whose internal details are not expanded at the current descriptive level |
| enumerative reasoning | 枚举推理 | Analysing finite steps and branches one by one |
| mathematical induction | 数学归纳法 | The main pattern of reasoning for loops and recursion |
| invariance / invariant | 不变性／不变式 | A property maintained at the boundaries of specified actions or loop iterations |
| sequencing control | 执行顺序控制 | Mechanisms determining the order, selection and repetition of actions |
| concatenation / selection / repetition | 顺序连接／选择／重复 | Three forms of decomposing computations |
| program family | 程序族 | A set of related programs for the same or similar tasks |
| manageability / adaptability | 可管理性／可适应性 | The ability to understand and modify programs and accommodate changes |
| state space | 状态空间 | The collection of possible states of a machine or program |
| instruction repertoire / order code | 指令集 | The available instructions of the current machine |
| closed subroutine | 闭式子程序 | A subroutine entered by a call that returns to its caller upon completion |
| procedure activation / incarnation | 过程激活／一次“化身” | A particular dynamic execution of a procedure and its associated local environment |
| re-entrant code | 可重入代码 | Code that permits multiple execution instances to coexist |
| own variable | `own` 变量 | An ALGOL 60 local variable intended to retain its value across procedure activations; the keyword is retained and its limitations discussed in the text |
| scope / life-time / identity | 作用域／生命期／身份 | A variable’s visibility, period of existence and particular identity |
| virtual machine | 虚拟机器 | A machine assumed available at the current abstraction level and simulated by a lower level |
| textual index / dynamic index | 文本索引／动态索引 | Indices identifying a position in program text and the current loop iteration respectively |
| pearl / necklace | 珍珠／项链 | The author’s metaphor for an independent refinement layer and a program composed of such layers |
| alphabetical order | 字典序 | Ordering by the digit symbols, with a proper prefix preceding its extensions |
| backtracking | 回溯 | Returning to an earlier choice and exploring the next candidate when the present one fails |
| partial function | 偏函数 | A function defined only on part of the set of inputs under consideration |
